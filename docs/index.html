简介

我是一名前端开发者，主要做 Web 界面与浏览器扩展。技术上偏好 原生能力优先：能用一个 CSS 变量解决的问题不引入主题库， 能用浏览器 API 完成的动作不装依赖。这不是保守，而是我踩过太多 「为了一个小功能背上一整套工具链」的坑之后形成的取舍。

写代码之外，我习惯把过程和结论整理成文章。一方面是给未来的自己留线索， 另一方面——能讲清楚的东西，才算真的掌握。
